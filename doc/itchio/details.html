Español

Este juego es una adaptación del juego de ZX Moe Flapper, que fue publicado como type-in para Break Space Issue 5.

Es un clon de Flappy Bird adaptado a Boriel BASIC.

Objetivos del proyecto

  • Comparar la versión Sinclair BASIC con Boriel BASIC.
  • Tener un ejemplo sencillo y funcional de Boriel BASIC.
  • Explorar las diferencias de rendimiento y legibilidad entre ambas versiones.

Cómo jugar

Pulsa cualquier tecla para que el pájaro aletee y esquiva los obstáculos. ¡Sobrevive el mayor tiempo posible!

Sobre la sencillez del juego

El juego podría haberse mejorado con más mecánicas, música durante la partida, animación del sprite... Sin embargo, uno de los objetivos es mantenerlo lo más sencillo posible como ejemplo de referencia. Respecto al original, prácticamente solo se ha añadido un sprite de 16x16 píxeles para el pájaro y scroll del suelo.

Detalles técnicos

  • Lenguaje: Boriel BASIC
  • Plataforma: ZX Spectrum 48K / 128K
  • Basado en el type-in original de Break Space Issue 5
  • Repositorio: github.com/rtorralba/flapper-boriel
  • Nota: la versión para Boriel se ha ralentizado 4× para evitar que el juego fuera demasiado rápido.

English

This game is an adaptation of ZX Moe's Flapper, originally published as a type-in listing in Break Space Issue 5.

This is a Flappy Bird clone adapted to Boriel BASIC.

Project goals

  • Compare the Sinclair BASIC version with Boriel BASIC.
  • Provide a simple, working example of Boriel BASIC.
  • Explore performance and readability differences between both versions.

How to play

Press any key to make the bird flap and dodge the incoming obstacles. Survive as long as you can!

On the simplicity of the game

The game could have been enhanced with more mechanics, in-game music, sprite animation... However, one of the goals is to keep it as simple as possible as a reference example. Compared to the original, practically the only additions are a 16x16 pixel sprite for the bird and ground scrolling.

Technical details

  • Language: Boriel BASIC
  • Platform: ZX Spectrum 48K / 128K
  • Based on the original type-in from Break Space Issue 5
  • Repository: github.com/rtorralba/flapper-boriel
  • Note: the Boriel version has been slowed down 4× to prevent the game running too fast.
