# Flapper Boriel

ZX Spectrum — [Boriel BASIC](https://zxbasic.readthedocs.io/)

This game is an adaptation of [ZX Moe](https://zxmoe.itch.io/)'s [Flapper](https://zxmoe.itch.io/flapper), originally published as a *type-in* listing in [Break Space Issue 5](https://breakspace.itch.io/break-space-issue-5).

## Project goals

- Compare the **Sinclair BASIC** version with **[Boriel BASIC](https://zxbasic.readthedocs.io/)**.
- Provide a simple, working example of **[Boriel BASIC](https://zxbasic.readthedocs.io/)**.
- Explore performance and readability differences between both versions.

## How to play

Press the **Space** key to make the bird flap and dodge the incoming obstacles. Survive as long as you can!

## Technical details

- Language: [`Boriel BASIC`](https://zxbasic.readthedocs.io/)
- Platform: ZX Spectrum 48K / 128K
- Based on the original type-in from [Break Space Issue 5](https://breakspace.itch.io/break-space-issue-5)
